# 源码候选的验证范围

本版本框架有六个源码包。两种语言的首页给出同一个离线示例。部分集成测试引用维护者的内部历史或夹具。详细的 Windows 桌面验收属于独立的 ForeContract-Desktop 项目。

The first-run check covers the deterministic Core / Fake / Scripted example. Some integration tests require external maintainer fixtures. Desktop validation belongs to ForeContract-Desktop.
